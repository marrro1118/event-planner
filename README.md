# event-planner

謎解き・イベント向けのスケジュール組み立てツール（開発中、仮の名称）。
参考: [algo-fes-planner](https://nazo-tools.github.io/algo-fes-planner/)（非公式ファンツール）。

## 開発

```sh
pnpm install
pnpm dev      # 開発サーバー
pnpm build    # 本番ビルド
pnpm test     # vitest
pnpm lint     # oxlint
```

## スタック

Vite + React 19 + TypeScript + Tailwind v4 + oxlint + vitest（pnpm）。
バックエンドなし。
